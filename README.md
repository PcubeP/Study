# Study Pack

A personal knowledge base — 70+ topic guides spanning AI/ML, software engineering, cloud, SAP, and business. Each guide is a self-contained, print-ready HTML file with syntax-highlighted code, callout blocks, and A4-optimised layout.

## Topics

AI & ML · LLMs · RAG · Prompt Engineering · LangChain · HuggingFace · PyTorch · TensorFlow · Scikit-learn · MLOps · Deep Learning · Vector Databases · LLM Evaluation  
Python · JavaScript · TypeScript · Java · C/C++ · React · Node.js · REST APIs · DSA · System Design  
Docker · Kubernetes · CI/CD · Linux · Networking · Observability  
Azure · SAP BTP · SAP AI Core · Enterprise Integration  
Data Engineering · Pandas · NumPy · Matplotlib · Jupyter  
Business · Freelancing · India Startup / Tax / Legal / Compliance

## Usage

Open `index.html` in a browser to browse all guides. Each guide can also be opened individually from `_content/` and printed to PDF.
